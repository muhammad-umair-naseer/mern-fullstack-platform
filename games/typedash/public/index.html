For the curious: how it works underneath
  • 10 Hz server snapshots stamped with server time, interpolated on the client — cars glide, they never jitter.
  • Server-authoritative progress. Validated and rate-limited; the race clock is synced NTP-style so everyone sees GO at the same instant.
  • Typing on your own never touches the server while you type — one result is sent at the end and checked against the typing-rate ceiling.
