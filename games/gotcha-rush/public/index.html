        Under the hood
        
    
          
  • Every puzzle is executed, not hand-typed. The bank is frozen by running each snippet through a real runtime (Node.js / CPython) — the output you're guessing is what actually printed.
    • 
          
  • The server does as little as possible. The puzzle bank is cached in your browser, so a match round is a puzzle id on the wire and the snippet is highlighted and animated locally. Solo Rush runs entirely in this tab and is only submitted at the end, where the server re-scores the whole answer log. Multiplayer rounds are graded on the server against a synced clock, so ping doesn't decide who was first.
    • 
          
  • Pluggable sandbox. The same runner abstraction supports local, Docker (no network, capped CPU/memory, read-only, non-root) and Judge0 execution — which also powers the Lab for editing a snippet and re-running it after a reveal.
