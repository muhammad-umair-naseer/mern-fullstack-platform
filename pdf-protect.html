This is the password that would be needed to change permissions below. If left blank, the open-password is reused.
This uses the PDF standard security handler (RC4, 40-bit — the original Acrobat-compatible password scheme defined in the PDF spec), implemented here with a from-scratch MD5/RC4 running as plain JavaScript. It's supported by essentially every PDF reader, but it's a legacy cipher, not modern-grade encryption — treat it as a access gate for casual sharing, not a defense against a determined attacker. Encrypted or already-locked source PDFs aren't supported.
